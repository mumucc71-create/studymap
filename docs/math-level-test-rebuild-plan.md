# 초4~고3 수학 레벨테스트 공통 구조·라우팅 1단계

## 적용 범위

이번 단계는 학년 선택 라우팅, 공통 문제 스키마, canonical 증거 계약, 세션 길이 계약, 고등 공통·선택과목 분리, 중3 초기 진단 계약만 구현한다. 기존 문제은행의 대량 재작성과 UI 개편은 포함하지 않는다.

## 공통 문제 및 증거

공통 모델은 문제 ID, 세부 canonical ID 또는 unit alias, 학년대, 답안형, 난이도 근거, 구조·풀이 경로 서명, 오개념 태그, 선수 개념, 독립 확인, 문항·정답, 채점 방식, 교육과정 범위, 예상 시간을 보존한다.

제출 증거는 canonical concept, 정오, 오개념, 구조·풀이 경로, 난이도, 독립 확인, 시각으로 변환한다. 숫자만 바뀐 동일 구조는 `canonicalConceptId + structureSignature` 기준으로 한 번만 집계한다. 광역 alias는 `UNIT_ENTRY` 증거이며 세부 개념 전체를 숙달시키지 않는다.

## 중3 초기·연속 진단

초기 진단은 제곱근과 실수, 다항식의 곱셈과 인수분해, 이차방정식, 이차함수, 피타고라스 정리, 삼각비, 원의 성질, 통계의 8단원에서 각각 4문항을 고른다. 네 역할은 기본 개념, 적용, 오류 진단, 독립 확인이다. 확률은 통계에서 분리한다.

기존 998문항 연속 진단 풀은 삭제하거나 수정하지 않고 후속 공급원으로 유지한다. `m3_trig_special_angles`, `m3_circle_foundations`, `m3_statistics_representative_range`, `m3_statistics_frequency_graphs`는 승인 스프링 모델을 보완 공급원으로 등록한다. 동일 구조 숫자 치환은 중복 숙달 증거가 아니다.

## 고등 분리 원칙

기존 고1·고2·고3 각 1문항은 실제 레벨테스트로 사용하지 않는다. 고1은 공통, 고2는 공통과 선택과목, 고3은 선택과목별 경로를 구분한다. 선택과목은 확률과 통계, 미적분, 기하로 분리하며 공통 필수처럼 섞지 않는다. 완성된 문제은행이 없으므로 이번 단계에서는 자연스러운 준비 상태만 제공한다.

## 출제 금지 registry
