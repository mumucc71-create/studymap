# Math Elite 수정 이력

## 2026-08-24 · 학생용 문장, 도형 표시, 세션 이탈 방지

### 수정한 문제

- 진행 중인 Elite 레벨테스트가 화면 초기화·로그인 복원 시점과 겹치면 홈 화면으로 바뀔 수 있던 화면 상태 경쟁을 막았다.
- 수학 42문항의 문제 문장을 명령형 한자식 표현 대신 학생이 읽는 문장으로 바꿨다.
- 수학 난이도(`mathematicalDifficulty`)와 문장 난이도(`languageDifficulty`)를 분리했다.
- 도형이 꼭 필요한 13문항에 `geometryData`를 추가했다.
- 화단 1문항, 삼각비 6문항, 원의 성질 6문항에 문제 조건과 일치하는 SVG 그림을 표시한다.
- 특히 `P-A-B`, `접선과 현이 이루는 작은 각`처럼 그림 없이 이해하기 어려운 표현은 점의 순서와 선분 관계를 풀어서 적었다.

### 화면·세션 규칙

- 진행 중 세션에서 다른 초기화 코드가 홈을 열면 Elite 화면을 다시 복원한다.
- 학생이 `그만두기`, `오늘은 여기까지`, 하단 `홈`을 직접 누르면 복원 표식을 지우고 정상적으로 홈으로 이동한다.
- Elite 화면 전환도 앱의 공통 화면 저장 경로를 사용한다.

### 검증 기준

- 수학 42문항 수와 정답 키를 그대로 유지한다.
- HIGH 21문항, TOP 21문항 분포를 유지한다.
- 그림이 필요한 13문항은 `geometryData`, 대체 설명, 렌더링 가능한 SVG를 모두 가져야 한다.
- `구하여라`, `작성하여라`, `증명하여라`, `P-A-B`, `작은 각` 표현이 학생 화면에 남지 않아야 한다.
- 문제 ID·구조·풀이 경로의 고유성을 유지한다.
