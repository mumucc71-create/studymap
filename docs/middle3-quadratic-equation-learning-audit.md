- 교육과정: 2015 개정 중학교 3학년

- 학습 문제: 108문항

- 기존 레거시 문제 재사용·수정: 0문항

## 4. 난이도 근거

- A3: 매개변수 또는 상황 조건에서 후보를 생성한 뒤 부호·범위·원식 검산으로 선별한다.
- A4: 숨은 완전제곱·인수 구조, 역추론, 경우 분류, 최소성, 표현 변환을 결합한다.
- A5: 잘못된 주장과 풀이를 반례·필요충분조건·모든 경우 분류·검증으로 분석한다.
- 계산량만 늘린 문항이나 단순 계산을 서술형으로 바꾼 문항은 사용하지 않았다.

대표 구조:

1. 이차항 소거 후보와 해 조건의 교집합 분류
2. 0이 될 수 있는 인수로 약분할 때 잃는 해 분석
3. 제곱근 풀이의 ± 필요충분조건과 세 부호 경우
4. 근의 공식 부호 오류가 우연히 맞는 모든 경우
5. 개별 대입 검산과 전체 해 완전성의 논리적 차이
6. 활용식의 해와 실제 상황 정의역을 동시에 만족하는 최종 조건

## 5. answer contract

`math-algebra-validator.js`를 수정하지 않고 다음 계약을 사용한다.

- 해 집합 순서 무관
- `2,-3`과 `-3,2` 동치
- `1±√2`와 두 해 나열 동치
- 중근 중복 제거
- 실근 없음과 빈 집합 동치
- 자연수·양수·비음수·구간 필터
- ± 누락 및 한 근만 제출 차단
- 조건 밖 해 포함 시 `OUT_OF_DOMAIN_ROOT_INCLUDED`
- 근호식·다항식 표현 동치
- 과정형 역순·누락·추가 단계 차단
- 서술형 `REVIEW_REQUIRED`

## 6. 저작 방식

문제의 prompt, 정답, 풀이 구조는 144개 저작 명세로 작성했다. 난수·숫자 치환 문제 생성은 사용하지 않았다. 공통 필드, ID, signature, 단계별 메타데이터 조립에만 결정적 팩토리를 사용했다.
