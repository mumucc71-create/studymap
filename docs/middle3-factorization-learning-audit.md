# 중3 다항식의 곱셈과 인수분해 스프링 학습 콘텐츠 감사

## 1. 감사 범위와 결론

- 교육과정: 2015 개정 중학교 3학년 수학
- 신규 콘텐츠: 144문항
- 학습 문제: 108문항
- 혼자 풀기: 36문항
- conceptId: 6개
- 단계: BASIC, A1, A2, A3, A4, A5
- 기존 114문항: 레거시 진단 문제로 보존하며 신규 모델에서 import하거나 복제하지 않음
- 작성 방식: 문제별 명시 저작. 공통 함수는 필드 정규화에만 사용하며 숫자 치환 문제 생성에는 사용하지 않음

이번 단계는 문제 모델, 설명, 힌트, 풀이, answer contract, 품질 테스트만 포함한다. UI, 추천 경로, Firebase, World, 브라우저 연결은 포함하지 않는다.

## 3. 답안형과 채점 계약

| answerType | 문항 수 | 판정 방식 |
|---|---:|---|
| MULTIPLE_CHOICE | 18 | 정규화한 선택지에서 정답 1개 확인 |
| SHORT_ANSWER | 46 | 정규화한 정답·허용답 비교 |
| EXPRESSION_INPUT | 44 | 대수 동치 또는 완전 인수분해 validator |
| STEP_ORDER | 18 | 저작·검산된 필수 단계의 정확한 순서, 누락·역순·추가 차단 |
| WRITTEN_RESPONSE | 18 | `REVIEW_REQUIRED`, 필수 논점 3개 이상과 부분답안 기준 |

`math-algebra-validator.js`의 기존 계약을 그대로 사용한다. 단변수 전개식은 `compareExpressions`, 인수분해식은 `assessFactorization`으로 판정한다. 전개된 채 제출한 답은 값이 같아도 `EQUIVALENT_NOT_FULLY_FACTORED`로 구분한다. 지원하지 않는 표현은 `UNSUPPORTED_EXPRESSION`, 빈 입력은 `INVALID_INPUT`, 서술형은 `REVIEW_REQUIRED`로 전달한다.

다변수 일반화는 자동 문자열 부분일치로 정답 처리하지 않는다. 자동 대수 판정 범위를 벗어나는 논증은 서술형 rubric으로 사람 검토한다.

## 4. conceptId별 품질 감사

### m3_polynomial_multiplication

- BASIC 목표: 단항식 분배, 음수 분배, x의 계수, 상수항을 직접 계산한다.
- A1 목표: 계수와 부호가 섞인 곱을 전개하고 매개변수를 한 단계 역추론한다.
- A2 목표: 두 곱의 합·차, 괄호 앞 음수, 교차항 오류를 구분한다.
- A3 통합 사고 근거: 계수와 상수항으로 매개변수를 복원하고 다른 곱으로 옮기거나, 두 다항식의 결합에서 목표 계수만 추적한다.
- A4 상 수준 근거: 정수쌍 후보, 영인수 분기, 공통 인수 전략, 소거 경로를 선택하고 검산한다.
- A5 최상 수준 근거: 대응 계수의 필요충분조건, 거짓 일반화의 반례, 항등식 성립 조건을 증명한다.
- 혼자 풀기 구조 차이: 단순 전개 대신 상수항 추적, 이중 조건 역추론, 소거 경로, 항등식의 필요충분조건을 사용한다.
- 주요 오개념: 분배 누락, 교차항 부호, 괄호 전체 빼기, 계수와 상수항 혼동.
- 검산: 모든 전개형 정답은 validator 동치 비교와 대표 부호 오류 비교를 통과했다.

### m3_multiplication_formula

- BASIC 목표: 네 기본 공식의 모양과 가운데항을 직접 확인한다.
- A1 목표: 계수 있는 완전제곱과 합차 공식을 한 단계 적용한다.
- A2 목표: 두 공식을 한 식에서 연결하고 차의 제곱·제곱의 차 오류를 진단한다.
- A3 통합 사고 근거: 완전제곱 계수를 역추론한 뒤 다른 공식으로 전환하고 부호 후보를 원식으로 검사한다.
- A4 상 수준 근거: 두 완전제곱 조건의 교집합, 공통 부분을 먼저 묶는 전략, 부호 두 경우 분류가 필요하다.
- A5 최상 수준 근거: 공식 오용이 성립하는 필요충분조건, 정수 계수 인수분해의 일반 조건과 반례를 증명한다.
- 혼자 풀기 구조 차이: 합·곱 역추론 뒤 제곱의 차 변환 또는 x항 소거 조건의 일반화를 사용한다.
- 주요 오개념: 2ab 누락, 첫 계수 제곱 누락, 합차 공식과 완전제곱 공식 혼동.
- 검산: 공식 전개 결과를 분배법칙으로 다시 계산했으며 고차 일반 인수분해는 사용하지 않았다.

### m3_common_factor

- BASIC 목표: 숫자·문자의 최대 공통인수와 음수 인수 선택을 이해한다.
- A1 목표: 최대공약수와 문자 지수의 최솟값을 함께 사용한다.
- A2 목표: 값이 같은 인수분해와 공통인수가 남지 않은 완전한 인수분해를 구분한다.
- A3 통합 사고 근거: 정확한 최대공약수 조건으로 후보를 만들고 거르거나, 두 식의 공통 일차인수를 계수 비교로 복원한다.
- A4 상 수준 근거: 두 gcd 조건, 범위, 묶은 뒤 남는 최대공약수 조건을 분류하고 경계를 검산한다.
- A5 최상 수준 근거: 완전 인수분해의 필요충분조건, 미완성 풀이의 오류 사슬, 음수 인수 관례와 수학적 완전성을 구분한다.
- 혼자 풀기 구조 차이: 지수 복원, 계수 역복원, 두 gcd 교집합, 부호 관례의 논증을 사용한다.
- 주요 오개념: 작은 공약수만 묶기, 공통 문자 누락, 음수 분배 오류, 완전성 미검사.
- 검산: 공통 숫자인수·문자인수가 남은 답을 각각 `EQUIVALENT_NOT_FULLY_FACTORED`로 차단했다.

### m3_factor_perfect_square

- BASIC 목표: 양 끝 항의 제곱과 가운데항 ±2ab를 확인한다.
- A1 목표: 계수가 있는 완전제곱식과 부호가 있는 매개변수를 처리한다.
- A2 목표: 공통인수를 먼저 묶고 잘못된 완전제곱식의 부호 오류를 진단한다.
- A3 통합 사고 근거: 계수 관계를 매개변수 하나로 바꾸고 합·부호·약수 조건으로 후보를 검증한다.
- A4 상 수준 근거: 두 완전제곱 조건의 후보 교집합과 최소 추가 상수를 역추론한다.
- A5 최상 수준 근거: 정수 계수 완전제곱식의 필요충분조건, 양 끝 제곱만으로 부족한 반례, 일반 계수 관계를 증명한다.
- 혼자 풀기 구조 차이: 양 끝 계수와 가운데항 검산, 역방향 매개변수 복원, 일반 계수 조건을 사용한다.
- 주요 오개념: 가운데항 생략, 끝항 부호 오해, 공통인수 선처리 누락.
- 검산: `(2x-5)^2` 유형의 완전 인수분해와 반대 부호 오답을 validator로 구분했다.

### m3_factor_difference_squares

- BASIC 목표: A²-B²와 (A+B)(A-B)를 직접 연결한다.
- A1 목표: 공통인수를 먼저 묶고 복합식 전체를 제곱의 밑으로 본다.
- A2 목표: 여러 단계 인수분해와 제곱의 합 오용을 구분한다.
- A3 통합 사고 근거: 주어진 한 인수가 합 쪽인지 차 쪽인지 경우를 만들고 범위로 걸러 다른 인수를 복원한다.
- A4 상 수준 근거: 두 분기, 범위, 비존재 판정, 복합 밑의 표현 변환을 함께 사용한다.
- A5 최상 수준 근거: 합차 꼴의 필요충분조건, 공통인수 오류 분석, 제곱의 합 반례와 분류 절차를 증명한다.
- 혼자 풀기 구조 차이: 매개변수 전달, 복합 밑의 단계 변환, 세 유형의 배타적 분류를 사용한다.
- 주요 오개념: 제곱의 합에 공식 적용, 공통인수 누락, 두 인수의 부호 동일 처리.
- 검산: 완전제곱식·제곱의 차의 validator 상태와 전개된 미완성 답의 차단을 확인했다.

### m3_factor_sum_product

- BASIC 목표: 합과 곱 조건에 맞는 정수 인수쌍과 부호를 고른다.
- A1 목표: 공통인수와 합·곱 인수분해를 연결하고 매개변수를 복원한다.
- A2 목표: 부호 분류, 공통인수, 곱만 맞는 잘못된 인수쌍을 구분한다.
- A3 통합 사고 근거: 범위·차·합·곱 조건으로 후보쌍을 생성하고 걸러 원식을 복원한다.
- A4 상 수준 근거: 모든 부호 인수쌍, 경계 조건, 최소 차, 양수 계수 조건을 분류한다.
- A5 최상 수준 근거: 정수 인수분해의 필요충분조건, 오답이라고 가정하는 오류, 상수항만으로 불충분한 완전 분류를 다룬다.
- 혼자 풀기 구조 차이: 순서 조건, 두 전개식 비교, 최소 인수 차, 네 분류의 판정 절차를 사용한다.
- 주요 오개념: 곱 조건만 확인, 부호 역전, 공통인수 미처리, 인수쌍 누락.
- 검산: 모든 단변수 이차식 인수분해 정답을 다시 전개했고 대표 잘못된 인수쌍을 오답으로 확인했다.

| A5 | 여러 인수분해 유형의 계수 조건을 배타적 판정 절차로 구성 | 전략 선택, 분류, 예외 검증 |

## 6. 수학 검산과 중복 검사

- 144개 정답을 문제의 `solutionSteps`와 독립 validator 계약으로 재확인했다.
- 객관식은 정규화 후 선택지 중 정답이 정확히 하나이다.
- 수식형 정답은 자기 자신뿐 아니라 전개 순서·인수 순서가 바뀐 동치 표현을 validator가 수용한다.
- 부호 오류, 계수 오류, 전개된 채 제출, 공통 숫자인수 남음, 공통 문자인수 남음을 대표 오답으로 검사했다.
- prompt 정확 중복, 숫자 제거 prompt 중복, `structureSignature`, `solutionPathSignature` 중복은 모두 0이다.
- 혼자 풀기 36문항은 같은 conceptId·stage의 학습 문제 세 문항과 구조·풀이 signature가 다르다.

내부 검산에서 계수 합, 최대공약수 후보, 경계 표현, 인수쌍 합계를 다시 계산하여 최종 데이터에 반영했다. 최종 품질 테스트는 초안의 설명이 아니라 현재 모델의 정답·조건·채점 계약을 대상으로 한다.

## 7. 교육과정 범위

사용 범위는 다항식의 곱셈, 네 곱셈 공식, 공통인수, 완전제곱식, 제곱의 차, 합과 곱을 이용한 단변수 이차식 인수분해이다. 일반 고차 인수분해나 고등학교 대수 도구는 사용하지 않았다. 매개변수는 중3 범위의 계수 비교, 정수 후보, 부호·범위 조건을 표현하는 데만 사용했다.
