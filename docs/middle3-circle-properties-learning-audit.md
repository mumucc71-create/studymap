## geometryData 계약

144문항 모두 다음 구조를 제공한다.

- 중심, 반지름, 점 좌표와 위치
- 원 위의 점
- 지름과 현
- 접선과 접점
- 호
- 중심각과 원주각
- 직각 표시와 같은 길이 표시
- 기준 호와 목표값

`validateCircleGeometryData`는 다음을 전수 검사한다.

1. 중심 표시와 양의 반지름
2. 원 위 점의 중심거리
3. 지름의 끝점·길이·중심 통과
4. 현 끝점이 원 위인지
5. 접점이 원 위인지
6. 외부점의 위치
7. 접선 방향과 접점 반지름의 내적이 0인지
8. 같은 외부점의 두 접선 길이가 같은지
9. 호 끝점·호의 크기·반원 180°
10. 중심각과 대응 호의 크기
11. 원주각과 대응 호의 절반 관계
12. 각도 범위와 기준 호 존재

## circleAnswerContract 및 의미 채점

`circleAnswerContract`는 `geometryData` 안에 중복하지 않고 문제 최상위에 둔다.

지원 관계:

- `TANGENT_RADIUS_PERPENDICULAR`
- `EQUAL_TANGENT_SEGMENTS`
- `CENTRAL_INSCRIBED`
- `SAME_ARC_INSCRIBED`

검증 결과:

- `OA`와 `AO`, `AB`와 `BA`처럼 점 순서만 다른 같은 선분은 허용한다.
- 접점이 다른 반지름을 선택하거나 접점이 아닌 곳의 수직 주장은 차단한다.
- 출발점이 다른 접선을 같은 길이 정리로 연결하지 않는다.
- 중심각과 원주각은 `interceptedArc`가 같고 크기가 2배일 때만 같은 관계로 인정한다.
- 원주각 두 개는 기준 호와 크기가 모두 일치할 때만 같은 호 관계로 인정한다.

## A3~A5 대표 구조

### A3

- 두 현의 길이와 중심거리를 함께 비교하여 후보 현을 선택한다.
- 접점·직각·직각삼각형 길이를 연결하고 다른 길이 조건으로 검산한다.
- 기준 호를 먼저 고른 뒤 중심각·원주각의 대응을 확인한다.
- 같은 외부점 조건을 확인한 뒤 두 접선 식을 세운다.

### A4

- 현의 반쪽 길이와 중심거리를 다른 표현으로 바꾸어 숨은 조건을 복원한다.
- 접선 판정에 필요한 최소 조건을 선택한다.
- 중심각과 원주각의 식을 역으로 세우고 가능한 호를 분류한다.
- 같은 호·반원 구조 중 먼저 적용할 성질을 선택한다.

### A5

- 접점이 아닌 곳에서의 수직 주장을 반례로 분석한다.
- 같은 길이의 두 현과 중심거리 관계의 필요충분조건을 설명한다.
- 서로 다른 외부점에서 출발한 접선에 같은 길이 정리를 적용한 오류를 분석한다.
- 서로 다른 호의 중심각·원주각을 비교한 풀이를 감사한다.
- 같은 호 판정의 끝점 조건과 반원의 역관계를 검증한다.

서술형은 모두 `REVIEW_REQUIRED`이며 필수 논점 3개 이상, 부분답안 항목, 관계 선택·기준 호·성질·계산·검산 기준을 제공한다.
